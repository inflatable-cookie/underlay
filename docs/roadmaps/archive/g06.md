## Intent and boundary

`g06` narrowed Underlay from a broad shared crate collection into a
small platform contract: typed safety primitives, the auth/session
contract reset with refresh rotation, HTTP safe-builder consolidation,
DB identifier and schema boundary normalization, the media repository
contract and adapter split, devtools bundle/store isolation, and the
six-consumer compatibility proof and release-note closeout. The same
generation then moved into the reference-grade reset, Rust hardening
lanes, god-file split repair batches, config-field retirements, and
bounded stale-drift repairs.
