# g01 - Extraction and Contraction

Status: archived
Kind: roll-up
Generation: `g01` (`g01.001`–`g01.098`)
Succeeded by: `g02`

## Intent and boundary

`g01` extracted Underlay's reusable foundation out of consuming
applications and contracted the retained public surface: auth systems and
their database migrations, shared UI patterns, the Nightfire extraction
readiness and package boundary lines, and the Poodle-era translation and
pruning waves. It closed with the `g01.098` recovery lane, which
recovered the real active shared-surface queue and rolled it into `g02`.

## Shipped outcomes

- Auth foundation: Underlay auth system roadmap, auth database
  migrations, and Rust test-coverage improvement.
- Pattern extraction: shared-pattern extraction, retained-patterns
  stop point, and client-surface organization.
- Package boundary: Nightfire extraction readiness, root package barrel
  reassessment, and the sibling-repo package boundary recovery.
- UI translation: Poodle translation wave for UI guides and the long-tail
  prune wave; `PageHeader`, `MediaPicker`, `DropdownMenu`,
  `MediaActionsMenu`, `ErrorBoundary`, `CopyActionsMenu`, and
  `DetailPageShell` successor/retirement waves.
- Closeout: `g01.097` pattern-catalogue routing, `g01.098`
  Poodle-era consumer-normalization and overhaul recovery.

## Canonical destinations

Lasting rules live in `docs/contracts/` (auth, transport, and
package-boundary contracts), `docs/architecture/`, and the Poodle-owned
UI layer. Nothing in this roll-up is executable.

## Migrations, limits, and retained risks

The Poodle-contraction residue was challenged directly per successor
wave; retired exports have no compatibility window beyond what Contract
`023` records. Archival doc-weight limits found here were later settled
in `g08.030`.

## Deferred items

None. The live queue moved to `g02` at closeout.
