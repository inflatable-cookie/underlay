`JobStore` adds a defaulted `mark_failure_fenced` method returning `JobFailureRecordOutcome::{Recorded(JobFailureOutcome), LostOwnership}` while preserving the existing `JobStore::mark_failure` signature. `JobRepository` overrides `mark_failure_fenced` to map `RepoError::Conflict` to `LostOwnership`, and `JobRunner` uses it so stale workers whose attempts fail or time out after stall recovery log a warning and continue instead of terminating the runner loop. `PgDeadLetterRepository::list` escapes `ILIKE` wildcards (`%`, `_`, `\`) with an explicit `ESCAPE '\'` clause, and `OutboxProcessor` isolates panicking domain event handlers (including drop panics on timeout cancellation) by rolling back and applying backoff instead of crashing the processor.

`underlay-media` center-crops source images to a square before resizing in `square_crop_image` to eliminate extreme-aspect-ratio OOM allocations (e.g., `1 x 16_384`), wires `RenditionConfig::square_thumbnails()` into `RenditionService`, and fetches source bytes once per version when both thumbnails and previews are enabled.

`underlay-blob` makes `LocalAdapter::head` descriptor-pinned (`openat(O_NOFOLLOW | O_NONBLOCK)` + `fstat` + `fgetxattr` from `base_dir`) inside `spawn_blocking` on Unix, includes signed `x-amz-meta-*` headers in S3 `UploadPlan::required_headers`, saturates `BlobUploadConfig::max_file_size_mb`, and uses `join_public_url` in `LocalAdapter::initiate_upload`.

`OpenAiCompatibleClient` disables HTTP redirects (`reqwest::redirect::Policy::none()`) and parses `https://` `base_url` values with `url::Url::parse`. `SesAdapter::build_content` rejects emails with neither text nor HTML body, `EmailAddress::validate_email` rejects internal whitespace, and `SuggestionQuery::with_hints` deduplicates hints while enforcing `MAX_RECENT_HINTS`.
