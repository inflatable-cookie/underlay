Hardened Rust authentication security boundaries and config validation across `underlay-auth*`.

- `underlay-auth`: `RoleHierarchy::can_manage` now fails closed on unknown caller or target roles (`RoleHierarchyError::UnknownRole`) and empty caller role slices (`RoleHierarchyError::InsufficientPrivileges`), matching `can_assign` for both standard and negative-rank custom hierarchies.
- `underlay-auth-oauth`: `GoogleOAuthAppService::handle_google_callback` rejects empty `csrf_state`, `code`, `pkce_verifier`, and `userinfo.sub`. `GoogleOAuthService` disables HTTP redirects (`reqwest::redirect::Policy::none()`) and parses static Google auth/token/userinfo URLs once.
- `underlay-auth-session`: `SessionService::refresh` revokes the active session row when `AccountProvider::account_state` returns `Ok(None)`. `SessionServiceConfig` fields are now private (breaking for callers constructing or reading `SessionServiceConfig` fields directly): construct with `SessionServiceConfig::new()` or `SessionServiceConfig::default()`, configure via `with_absolute_session_timeout(timeout)` and `with_refresh_fingerprint_strict(strict)`, and read via `absolute_session_timeout()` and `refresh_fingerprint_strict()`.
- `underlay-auth-password`: `PasswordAuthService` rejects passwords exceeding 1024 bytes before cloning, Argon2id, or HIBP checks; `reset_password` clears failed login counters and lockouts; HIBP local HTTP allowance no longer accepts `0.0.0.0`.
- `underlay-auth-email-totp`, `underlay-auth-jwt`, `underlay-auth-totp`, `underlay-auth-webauthn`, `underlay-auth-state-postgres`: clamped config setters (`EmailTotpConfig` code length and positive expiries/attempts, `JwtConfig` lifetime upper bounds, `TotpConfig::skew_steps` upper bound), logged underlying `WebauthnError` in attested passkey flows and missing `cred.counter` fields, avoided double JSON parsing in `passkey_sync_info_from_json`, and switched `AuthStateStore::create` handles to random UUIDv4.
