Harden `underlay-http`, `underlay-http-client`, `underlay-ratelimit`, `underlay-audit`, `underlay-security-alerts`, and `underlay-testing`:

- `underlay-http`: Coalesce `CachedListEndpoint::serve` errors across single-flight callers without re-executing `build()` or firing `on_hit()` on the leader's cache miss. Fix `CorsConfig` mirror-origin handling when `allow_credentials` is false. Reject non-IPv6 `public_host` values containing `:` or brackets in `HttpServerConfig::try_new` and document `PORT` bind-address behavior. Bound `error_logging_middleware` background DB writes with a semaphore, widen the `microcache_expires_entries` test margin, and drop the unused `urlencoding` dependency.
- `underlay-http-client`: Disable env proxy bypasses on `HttpClient::external()` via `.no_proxy()`, add non-blocking `validate_external_url_async`, document `validate_external_url` as blocking, and block IPv6 6to4 (`2002::/16`), Teredo (`2001::/32`), documentation (`2001:db8::/32`), and local-use NAT64 (`64:ff9b:1::/48`) ranges in `is_public_ip`.
- `underlay-ratelimit`: Round non-zero sub-second durations up in `RateLimitResult::retry_after_secs()`, add `PostgresBackend::prune_expired`, avoid inserting map entries when `max_requests == 0` in `InMemoryBackend::check_and_increment`, and deny over-limit races in the default `RateLimitBackend::check_and_increment`.
- `underlay-audit`: Generalize `append_audit_log_to_table` to accept `impl PgExecutor<'_>` for transactional writes and add an `id DESC` tiebreaker to `list_audit_logs_from_table`.
- `underlay-security-alerts`: Serialize `SecurityAlertType` in `snake_case` and add `SecurityAlertConfig::validate()` to reject non-positive durations and thresholds.
- `underlay-testing`: Check `output.status.success()` in `assert_docker_available()`, switch async DB fixture/migration helpers to `tokio::fs` while propagating `read_dir` errors, re-export `RequestBuilder`, and remove the unused `reqwest` dependency.
