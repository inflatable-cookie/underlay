Outbox processing backs off and skips failing domain events so a poison pill cannot starve newer events, and adds graceful shutdown loops (`run_with_notifier_until_shutdown`, `run_polling_until_shutdown`). PostgreSQL job runners add `run_with_notifier_until_shutdown`, respect `batch_size`, coalesce buffered notifications, and fence `mark_succeeded_for_job` on the claimed attempt count. `JobRunner::run_once` isolates panicking handlers as job failures instead of terminating the runner loop.

Media image decoding enforces explicit pixel dimension and allocation limits (128 MiB default), guards zero thumbnail dimensions, and fetches rendition sources through bounded blob reads (`get_bytes_bounded` with configurable `max_source_bytes`). Stale `underlay-media-postgres` doc references are removed.

S3 `get_bytes` redacts raw body-read errors, replaces unchecked length casts with checked conversions, and drops the unused `base64` dependency. `EmailAddress::new` and `EmailAddress::with_name` store trimmed addresses while rejecting control characters, `SmtpConfig` adds a configurable connection timeout, `OpenAiCompatibleClient` sets a connect timeout and validates local HTTP hosts with `url::Url`, and `SuggestionParams::recent_hints` caps returned hints at `MAX_RECENT_HINTS`.
