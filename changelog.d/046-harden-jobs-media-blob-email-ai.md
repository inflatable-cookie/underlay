Outbox processing backs off and skips failing domain events across batch boundaries within each drain pass so a poison pill cannot starve newer events, and adds graceful shutdown loops (`run_with_notifier_until_shutdown`, `run_polling_until_shutdown`). PostgreSQL job runners add `PostgresJobRunnerShutdownExt::run_with_notifier_until_shutdown`, respect `batch_size`, and coalesce buffered and socket-queued notifications. Breaking pre-1.0 completion fencing: `JobStore::mark_success` and `JobRepository::mark_succeeded` now take `&Job` (with `JobRepository::mark_succeeded_attempt` for explicit `(job_id, expected_attempts)` fencing) so stale workers cannot finalize a reclaimed job; `JobStore::mark_success` returns `JobCompletionOutcome::{Succeeded, LostOwnership}` so runners treat lost ownership cleanly without exiting. `JobRunner::run_once` isolates panicking handlers as job failures instead of terminating the runner loop.

Media image decoding enforces explicit pixel dimension and allocation limits (128 MiB default), guards zero thumbnail dimensions, and fetches rendition sources through bounded blob reads (`get_bytes_bounded` with configurable `max_source_bytes`). Custom `BlobAdapter` implementations used with `RenditionService` must override `get_bytes_bounded` because the default implementation returns `BlobError::Unsupported`. Stale `underlay-media-postgres` doc references are removed.

S3 `get_bytes` redacts raw body-read errors, replaces unchecked length casts with checked conversions, and drops the unused `base64` dependency. `EmailAddress::new` and `EmailAddress::with_name` store trimmed addresses while rejecting control characters, `SmtpConfig` adds a configurable connection timeout, `OpenAiCompatibleClient` sets a connect timeout and validates local HTTP hosts with `url::Url`, and `SuggestionParams::recent_hints` caps returned hints at `MAX_RECENT_HINTS`.
